# KeebOS
Best firmware for the KeebCard!  
The KeebCard sadly only has 8kb of flash memory, so apps are very limited. I'm still happy how this turned out.

## Features:
### Games
* Snake
* Dino
* Race (switch lanes)
* Memory (Simon)
### Productivity
* Stopwatch
* Timer
* Dice
### Settings/others
* Battery level (percentage + voltage)
* Auto sleep time
* Clock adjust/calibration
* Button calibration
* Auto deep sleep after 15sec(default) in main menu
* Wake-up from 2sec long press
* Quit from apps with long center press
